제2장 ⚙️ 주방 KDS 매장 관리자 맞춤 설정 (헤더의 '⚙️ 매장 설정' 버튼 클릭 시 팝업)
⏱️ 탭 1: 조리 및 배달 소요 시간 직접 수정
  • 여유 / 혼잡 / 피크 각 단계별 포장 및 배달 소요 시간(분)을 현장 상황에 맞춰 숫자로 직접 입력합니다.
  • [저장]을 누르면 고객 스마트폰 자사몰에 소요 예정 시간이 즉각 반영됩니다.
  • 피크타임 시 고객의 조기 방문 혼선을 막기 위해 짧은 시간대 선택이 자동 비활성화됩니다.
📢 탭 2: 실시간 고객 공지 문구 등록
  • 우천/폭설, 당일 조기 마감, 특정 재료 소진, 영월 축제 등 긴급 공지 문구를 직접 타이핑하여 등록합니다.
  • 원터치 템플릿 칩: [🌧️ 우천 배달지연], [❄️ 폭설 안전운행], [🍗 재료 조기소진], [🎉 주말 피크안내] 클릭 시 자동 입력 지원.
  • 등록 즉시 고객 자사몰 최상단에 강조 배너로 안내됩니다.
🍗 탭 3: 메뉴별 원터치 품절(Sold-out) 제어
  • 특정 부위(윙, 봉, 콤보, 다리)나 소스, 사이드 메뉴가 품절되었을 때 스위치(토글)를 [품절]로 켭니다.
  • 품절 처리된 메뉴는 고객 자사몰에서 붉은색 '🔴 품절' 뱃지가 붙고 장바구니 담기가 즉시 차단됩니다.
  • 재료가 재입고되면 스위치를 다시 끄면 즉시 판매가 재개됩니다.
🔊 탭 4: 주방 알림음 종류 & 볼륨 조절
  • 알림음 종류: 배달의민족 스타일 딩동, 맑은 도레미 벨, 긴급 사이렌, 축하 팡파레, 음성 합성(TTS [티티에스]) 중 주방 소음도에 따라 선택.
  • 볼륨 조절기: 0%부터 100%까지 주방 환풍기 소음에 맞춰 슬라이더로 조절.
  • [소리 미리듣기] 버튼으로 테스트 후 저장 가능합니다.

⚠️ 법적 처벌 경고 (청소년보호법 제28조 위반 시)
미성년자 주류 판매 적발 시: 3년 이하의 징역 또는 3천만원 이하의 벌금 및 식품위생법에 따른 영업정지(1차 2개월, 2차 3개월, 3차 영업취소) 처분을 받습니다.
1. 주방 KDS 화면 및 영수증 자동 알림
  • 생맥주, 병맥주, 소주 등 주류가 포함된 주문은 주방 주문 카드에 🚨 [주류 포함] 성인 신분증 대면 검사 필수 뱃지가 번쩍입니다.
  • 인쇄되는 주방 주문 영수증 하단에 청소년보호법 법정 경고문이 자동 인쇄됩니다.
2. 포장 방문 및 배달 대면 검사 요령
  • 포장 고객: 매장 카운터에서 음식 전달 전 반드시 실물 신분증(주민등록증, 운전면허증, 모바일 신분증)을 확인합니다.
  • 배달 기사님: 주류 포함 영수증을 기사님께 강조 전달하고, 문앞 비대면 요청 시에도 주류는 반드시 대면 확인 후 전달하도록 안내합니다.
  • 신분증 미지참 또는 확인 거부 시 주류 결제 취소 후 음식만 전달합니다.
