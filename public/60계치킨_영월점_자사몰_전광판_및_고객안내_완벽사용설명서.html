👑 60계대표 박종숙 사모님을 위한 자사몰 전광판 초간편 가이드

사모님! 어려운 컴퓨터 용어나 기능은 신경 쓰실 필요가 전혀 없습니다!
손님 주문이 들어오면 딱 2개 버튼( [🔥 조리 시작] ➔ [🛍️ 조리 완료] )만 순서대로 1번씩 누르시면 모든 안내가 손님 휴대폰으로 자동으로 끝납니다.
초등학생도 1분 만에 바로 따라 할 수 있도록 가장 쉽게 정리해 드립니다.

★ 필수 아침 준비 출근하셔서 태블릿 켜고 화면 아무 곳이나 딱 1번 "톡!" 터치하기!

태블릿 인터넷은 보안 정책상 처음 켰을 때 사람이 화면을 1번 터치해 줘야만 소리가 활성화됩니다.
아침에 출근하셔서 전광판 주소 열린 화면을 손가락으로 1번 톡 치셔야 "카톡! 🔔 포장 주문이 들어왔습니다!" 소리가 쩌렁쩌렁 크게 울립니다!

1단계 소리 듣고 전광판 화면 보기 ("카톡! 🔔 포장 주문 도착")
  • 노란색 카드 = [포장 손님] | 파란색 카드 = [배달 손님]
  • 손님이 주문한 치킨 종류(크크크골드, 간지 등)와 부위(뼈, 순살, 윙봉), 맛 변경 옵션을 큰 글씨로 확인합니다.
2단계 기름솥에 치킨 넣을 때 ➔ [🔥 조리 시작] 버튼 딱 1번 터치! 🔥 조리 시작
  • 치킨 조리를 시작할 때 전광판의 주황색 [🔥 조리 시작] 단추를 손가락으로 1번 누릅니다.
  • 버튼이 [조리 중]으로 바뀌며, 손님 휴대폰 화면에 "치킨을 맛있게 튀기고 있어요!" 하고 무료 자동 안내됩니다.
3단계 치킨 상자에 담고 포장 끝났을 때 ➔ [🛍️ 조리 완료] 버튼 딱 1번 터치! 🛍️ 조리 완료
  • 치킨 조리와 포장을 모두 마쳤을 때 초록색 [🛍️ 조리 완료] 단추를 손가락으로 1번 누릅니다.
  • 손님 휴대폰 화면에 "치킨이 완성되었습니다! 카운터에서 찾아가세요!" 안내가 즉시 떠서 손님이 매장으로 픽업하러 옵니다.
4단계 손님 오시면 치킨 건네드리고 결제 확인하기
  • 매장에 손님이 오시면 주문 번호나 고객 성함(전화번호 끝자리)을 확인하고 치킨을 반갑게 건네드립니다.
  • 현장 카드/현금 결제 또는 계좌이체(신한 110-189-261588 박종숙) 입금을 확인하시면 주문이 완벽하게 끝납니다!
💡 사모님 안심 꿀팁: 실수로 버튼을 잘못 누르셨거나 잘 안 눌러졌어도 걱정 마세요!
화면 맨 위 [새로고침 🔄] 단추를 누르면 화면이 다시 깨끗하게 정렬됩니다. 고객이 주문 취소를 요청했을 때만 [주문 취소 ❌]를 누르시면 됩니다.

전광판 화면 백과사전

[카테고리 2] 주방 전광판 모든 기능 완전정복 (1편: 화면과 카드)

🍗 60계치킨 강원영월점
2페이지 / 총 5페이지
🖥️ 주방 전광판 화면은 [상단 조작 막대]와 [주문 카드 목록]으로 구성되어 있습니다.
화면에 보이는 모든 단추의 이름과 역할을 초등학생 눈높이로 하나씩 설명해 드립니다.

1. 화면 맨 위에 있는 상단 조작 버튼 4총사

① [소리 켜기 배너] 🔊 (출근 시 필수)

화면 맨 위에 노란색 또는 파란색 띠로 '소리를 켜려면 화면을 터치하세요'라고 뜹니다. 이 띠를 손가락으로 1번 누르면 주문 알림 음성("카톡! 🔔 포장 주문 도착")이 활성화됩니다.

② [⏸️ 주문 일시정지] 단추 (피크타임 전용)

가게에 손님이 너무 몰려 밀리거나 닭/기름이 떨어졌을 때 딱 1번 누르세요!
손님 자사몰 화면에 '현재 주문 폭주로 잠시 준비 중입니다'라고 뜨며 신규 주문이 자동으로 잠깁니다.
여유가 생기면 다시 [▶️ 주문 재개]를 누르시면 손님 주문이 정상 접수됩니다.

③ [새로고침 🔄] 단추 (화면 최신화)

화면이 멈춘 것 같거나 최신 주문을 즉시 다시 불러오고 싶을 때 누르세요. 전광판이 1초 만에 최신 인터넷 상태로 다시 깨끗하게 정렬됩니다.

④ [⚙️ 매장 설정] 톱니바퀴 (시간/품절 관리)

치킨 조리 예상 시간을 바꾸거나, 재료가 떨어진 메뉴를 '품절' 처리할 때 누르는 설정창입니다. (3페이지에서 상세히 설명해 드립니다!)

2. 주문 카드 보는 법 (노란색은 포장! 파란색은 배달!)

[카테고리 2 계속] 매장 설정(품절/시간) & 매출 분석과 단골 관리

🍗 60계치킨 강원영월점
3페이지 / 총 5페이지

1. [⚙️ 매장 설정] 톱니바퀴를 눌렀을 때 나오는 4가지 기능

① [품절 메뉴 관리] (재료가 떨어졌을 때)

• 특정 치킨이나 부위(예: 크크크골드 콤보, 쯔란, 치즈볼 등)의 재료가 다 떨어졌을 때 씁니다.
• 메뉴 목록에서 해당 메뉴 오른쪽 스위치를 '툭' 누르면 [품절]로 바뀌며, 손님이 자사몰에서 주문을 못 하게 자동으로 막힙니다!
• 다음 날 재료가 들어오면 다시 터치해서 [판매 중]으로 켜두시면 됩니다.

② [조리 예상 시간 설정] (비 오거나 주문 폭주할 때)

• 평소 보통 날: [보통 20분]으로 둡니다.
• 비가 오거나 단체 주문이 밀렸을 때: [바쁨 35분] 또는 [피크 50분] 버튼을 누르면, 손님 휴대폰에 "지금 주문 시 약 50분 소요됩니다"라고 자동으로 계산되어 안내됩니다.

③ [매장 긴급 공지사항 작성] (손님 화면 맨 위에 띄우기)

• 손님들이 자사몰에 들어오자마자 보게 되는 공지 문구를 적는 곳입니다.
• 예시: "오늘 폭설로 인하여 배달이 15분 정도 지연될 수 있습니다. 정성껏 조리하겠습니다."라고 적고 [저장]을 누르면 손님 화면에 예쁘게 뜹니다.

④ [소리 및 볼륨 테스트] (알림 소리 점검)

• 전광판에서 나오는 음성 안내의 크기를 키우거나 줄일 수 있습니다.
• [소리 테스트 🔊] 단추를 누르면 "카톡! 포장 주문이 들어왔습니다!" 음성이 매장에 울려 퍼지며 소리가 잘 나는지 확인해 줍니다.

2. [📊 매출 및 수수료 절감 분석] & [👥 단골 관리] 탭

💰 사모님이 배달앱 중개 수수료를 얼마나 방어했는지 보여줍니다!

• 자사몰 주문은 배달의민족이나 요기요에 바치는 '중개 수수료(12~15%)'와 '결제 수수료'가 0원입니다!
• 상단 [매출 분석 📊] 단추를 누르면:
   1) 오늘 자사몰로 판매한 총매출액 (예: 오늘 850,000원 판매)
   2) 배달앱에 안 뜯기고 사모님 통장에 100% 남은 순수 수수료 절감액 (예: 오늘 127,500원 절감 성공!)
   3) 일주일간, 한 달간 누적 절감액을 표와 그래프로 예쁘게 보여줍니다.

💖 우리 매장을 자사몰로 자주 찾아주시는 고마운 VIP 단골 명단!

• 화면 상단 [단골 관리 👥] 단추를 누르면 손님들의 전화번호와 주문 횟수가 순서대로 정리되어 있습니다.
• 손님이 주문할 때마다 자동으로 차곡차곡 쌓아드린 '적립 포인트'를 점주님이 직접 확인하실 수 있습니다.
• 단골손님이 매장에 오셔서 "저 포인트 얼마 있어요?" 물어보시면 여기서 전화번호로 1초 만에 찾아 안내해 드릴 수 있습니다.

손님 응대 실전 대화법

[카테고리 3] 손님 응대 & 질문 해결 대화 가이드

🍗 60계치킨 강원영월점
4페이지 / 총 5페이지
💬 손님이 매장에 오셔서 물어보실 때, 사모님께서 아래 적힌 대로 친절하게 말씀만 하시면 됩니다!
배달의민족보다 훨씬 이득이라는 사실을 알려주시면 손님들이 무조건 자사몰 단골이 됩니다.
질문 1. "사장님, 배민이나 요기요 말고 여기서 시키면 뭐가 좋은가요?"

사모님 대답:
"손님! 배민으로 시키시면 제값 다 내시는데, 저희 가게 QR로 포장 주문하시면 2,000원을 즉시 할인해 드려요! 게다가 쫄깃하고 달콤한 미니 쫀득볼 5개도 공짜 서비스로 팍팍 챙겨드립니다! 배달도 쫀득볼 10개를 무료로 드려요!"

질문 2. "어떻게 주문하는 거예요? 어플(앱)을 또 깔아야 하나요?"

사모님 대답:
"아니요, 어플 귀찮게 안 까셔도 됩니다! 손님 스마트폰 카메라 켜서 저희 치킨 박스나 매장에 붙은 네모난 QR코드에 살짝 비추기만 하시면 주문 화면이 바로 열려요! 메뉴 터치하고 주문하기 누르시면 끝납니다!"

질문 3. ★(핵심) "포인트가 뭐예요? 이거 진짜 현금처럼 쓸 수 있는 건가요?"

사모님 대답:
"그럼요, 손님! 저희 자사몰에서 치킨 시키실 때마다 현금처럼 쓰는 포인트가 500원~1,500원씩 차곡차곡 쌓여요! 1포인트는 진짜 현금 1원이라서, 다음 주문하실 때 '포인트 사용' 누르시면 그만큼 치킨값이 싹 깎여서 현금처럼 바로 쓰실 수 있습니다! 배민은 이런 거 안 주잖아요!"

질문 4. ★(핵심) "내 포인트가 지금 얼마 쌓여있는지 어떻게 확인하나요?"

사모님 대답:
"손님 스마트폰 자사몰 화면 맨 위에 [내 포인트 조회] 누르시고 전화번호만 넣으시면 몇천 원이 쌓여있는지 1초 만에 바로 보여요! 아니면 제가 여기서 주방 전광판으로 바로 찾아봐 드릴게요! (전광판 [단골 관리] 누르고 손님 번호 검색 ➔ '손님, 지금 3,000원 쌓여 있으세요!')"

질문 5. "포인트는 얼마나 쌓아주고, 무료로 주는 건 치즈볼인가요?"

사모님 대답:
"뼈·순살은 2,000원 포장 할인에 500P가 더 쌓이고, 배달이나 콤보·윙봉은 무려 1,500P씩 팍팍 쌓아드려요! 무료로 드리는 서비스는 일반 치즈볼이 아니라 한입에 쏙 들어가는 바삭쫄깃한 '미니 쫀득볼'입니다! 포장 5개, 배달 10개씩 드립니다!"

🎁 손님에게 꼭 안내해야 할 60계 영월점 자사몰 4대 특권 총정리
  1. 포장 주문 시 2,000원 즉시 할인! (치킨 1마리당 2,000원씩 절약)
  2. 포장 시 미니쫀득볼 5개 무료 증정! / 배달 시 미니쫀득볼 10개 무료 증정!
  3. ★ 현금처럼 쓰는 포인트 팍팍 적립! (1포인트 = 1원 현금 할인)
       • 뼈 / 순살: 포장 2,000원 할인 + 500P 적립 / 배달 1,500P 적립!
       • 콤보 / 윙봉: 포장 1,500P 적립 / 배달 1,500P 적립! (순살세트 1,000P~1,500P)
